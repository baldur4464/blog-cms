# ADR-001 – Projektvision und Scope

Status: Accepted

## Projektziel

Entwicklung eines modernen, selbst hostbaren Open-Source Blog-CMS auf Basis von Java Spring Boot, React und PostgreSQL.

Das System soll sowohl als klassisches Blog-CMS als auch als Headless-CMS nutzbar sein.

Der Fokus liegt auf:

* Hoher Wartbarkeit
* Erweiterbarkeit
* Klarem API-Design
* Modernem Admin-Interface
* Open-Source-Tauglichkeit

---

## Zielgruppe

* Einzelne Blogger
* Entwickler
* Kleine Teams
* Self-Hosting-Nutzer
* Open-Source-Community

---

## Technologiestack

Backend:

* Java 21
* Spring Boot 3
* Spring Security
* PostgreSQL
* Flyway

Frontend:

* React
* TypeScript
* Vite
* React Router
* TanStack Query
* Tiptap

---

## Architektur

* Monolithischer Backend-Service
* REST API
* React Admin Panel
* PostgreSQL als primäre Datenbank

Keine Microservices in Version 1.

---

## Funktionen in Version 1

### Benutzerverwaltung

* Login
* Logout
* Rollenbasierte Berechtigungen

### Content Management

* Beiträge erstellen
* Beiträge bearbeiten
* Beiträge veröffentlichen
* Beiträge archivieren
* Entwürfe speichern

### Kategorien

* Kategorien anlegen
* Kategorien bearbeiten
* Kategorien löschen

### Tags

* Tags anlegen
* Tags bearbeiten
* Tags löschen

### Medien

* Dateien hochladen
* Bilder verwalten

### Öffentliche API

* Beiträge abrufen
* Kategorien abrufen
* Tags abrufen

---

## Nicht Bestandteil von Version 1

* Kommentare
* Newsletter
* Mehrsprachigkeit
* Mehrmandantenfähigkeit
* Plugin-System
* Theme-System
* GraphQL
* Analytics

Diese Funktionen können in späteren Versionen ergänzt werden.

---

## Qualitätsziele

* REST-konforme API
* Vollständige OpenAPI-Dokumentation
* Automatisierte Datenbankmigrationen
* Testbarkeit
* Erweiterbarkeit
* Docker-Unterstützung
